## Deploy without GitHub
1. Unzip the project.
2. In Vercel, use the available upload/drop deployment flow or create a new static project with these files.
3. If prompted for an output directory, use `.`. No build command is needed.
4. Test the deployed page, video, and both checkout links.

If your existing Vercel project has no edit/overwrite option, deploy this as a new project and assign your desired domain from project settings.

## Exact logo
The supplied logo is not embedded in this ZIP; the page currently uses a simple CSS-built brand-inspired mark. Add your exact logo image file to the project and replace the `.brand-mark` element in `index.html` with an `<img>` if you want the exact artwork displayed.
